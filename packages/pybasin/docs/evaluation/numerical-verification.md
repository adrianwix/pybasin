# Numerical Verification

The shared [case studies](https://adrianwix.github.io/pybasin/case-studies/overview/) contain the current numerical comparisons with bSTAB. Their tables and figures are generated by the integration test suite, which keeps the published evidence tied to executable checks.

The comparison artifacts live under `artifacts/results/`, while publication figures live under `docs/assets/case_studies/`. Keeping those destinations at the repository root lets a single case study exercise pybasin and tstorch together.

Run the verification suite and refresh its documentation artifacts with:

```bash
uv run pytest tests/integration --generate-artifacts
```

Not every future case study needs an external ground truth. For new systems, the page should state the invariants, convergence checks, or independent implementations used to support the result.
